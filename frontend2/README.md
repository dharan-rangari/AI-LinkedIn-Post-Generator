# Frontend - LinkedIn AI Post Assistant

React (Vite) + Tailwind CSS frontend for the LinkedIn Post Generator.
See the root `README.md` for full setup instructions.

Quick start:

```bash
npm install
npm run dev
```

The app expects the backend to be running and reachable at the URL configured
in `VITE_API_BASE_URL` (see `.env`), which defaults to `http://localhost:8000/api`.
